# 03 FOR LOOP

This folder contains exercises focused on basic Python for loops.

================================================================================

03_01_Stars
    > Gets length of rectangular triangle
    > Prints a triangle of stars line by line

03_02_Interest
    > Gets capital, interest rate, and number of years
    > Calculates simple interest year by year
    > Calculates compound interest year by year
    > Outputs yearly interest and total for both methods

03_03_Palindrome
    > Gets text input
    > Reverses the text
    > Checks if the text is a palindrome
    > Outputs reversed text and palindrome status
