# 01 IN AND OUTPUT

This folder contains exercises focused on console input and output.

================================================================================

01_01_TextLength
* Gets the length of a string
* Output length

01_02_FirstAndLastName
* Asks for first and last name
* Gets name lengths
* Calculates space needed for the names
* Output everything

01_03_SumOfThreeNumbers
* Gets 2 numbers using 2 variables
* Sums the first two numbers and outputs result
* Add third number using third variable to result
* Output new result

01_04_JustOneVariable
* Gets 3 diffrent numbers using same variable
* not storing last number, instead directly multiplying by next input
* Output result

01_05_Minimum
* Gets 2 numbers
* Outputs number with smaller value
