# 05 MODULO OPERATOR

This folder contains exercises on the use of the modulo operator.

================================================================================

05_01_FizzBuzz
* Get the range for FizzBuzz
* Loop from 1 to the range
* Print "Fizz", "Buzz", or "FizzBuzz" depending on i

05_03_SecsInDayHrMinSec
* Prompt the user for a number of seconds
* Validate that the input is a non-negative integer
* Convert seconds into:
  - Days
  - Hours
  - Minutes
  - Remaining seconds
* Display the results clearly
* Display invalid input messages in color
